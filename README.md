# NotebookLM_Power-01
In Construction...

Este projeto de ensino explora o uso da Inteligência Artificial como uma verdadeira ferramenta de aprendizagem ativa. Este projeto prático avalia:
- pensamento crítico;
- curadoria de fontes e
- organização do conhecimento
para criar um Caderno Temático no NotebookLM. 😎
 
O que não vai faltar aqui neste Repositório "Nota 10"?
Para que o projeto demonstre maturidade técnica e seja notado, estruturei este repositório contemplando os seguintes itens:
 - Contexto e Objetivos: Iniciando o README explicando qual foi o assunto de interesse escolhido para o meu caderno temático e definindo claramente quais são os meus objetivos de estudo com esse material.
 - Curadoria de Fontes: Lista (ou insira os links) de 3 a 5 fontes abertas em texto ou PDF que selecionei e fiz o upload no NotebookLM.
 - Engenharia de Prompts e "Cicatrizes": Documentação das perguntas estratégicas que elaborei e as variações de prompts que testei.
 - Dica Extra de ouro: registro das respostas obtidas, minhas referências e também as dificuldades que encontrei para extrair a melhor resposta da IA (troubleshooting), com o intuito de mostrar o raciocínio por trás dos resultados!
 - Miniguia de Estudo (Entrega Final): Apresentação do resultado final consolidado, contendo:
  - Resumos estruturados do assunto;
  - Um glossário com os principais conceitos aprendidos;
  - Um conjunto de prompts reutilizáveis que possam apoiar futuras revisões sobre o tema.

Por hora é isso, acompanhe a evolução deste repositório e deixe feedbacks, pois são muuito bem-vindos.
